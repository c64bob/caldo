# Story 25.1 — Globales Quick-Add-Overlay

## Name
Story 25.1 — Globales Quick-Add-Overlay

## Status
Offen

## Ziel
Quick Add wird von jeder Kernansicht aus schnell erreichbar.

## Eingangszustand
Quick Add existiert als Seite, aber nicht als produktives globales Overlay.

## Ausgangszustand
Nutzer koennen eine Aufgabe starten, erfassen und speichern, ohne die aktuelle Ansicht zu verlieren.

## Akzeptanzkriterien
* Das Overlay oeffnet ueber sichtbare Aktion und Tastaturkurzbefehl.
* Der vorherige Kontext bleibt nach Speichern oder Abbrechen erhalten.
* Das Overlay ist auf Desktop, Tablet und Mobile nutzbar.
* Fehlgeschlagene Writes bleiben im Overlay sichtbar.
