# Story 26.5 — Suche als gespeicherten Filter sichern

## Name
Story 26.5 — Suche als gespeicherten Filter sichern

## Status
Umgesetzt

## Ziel
Eine aktuelle Suche kann in einen gespeicherten Filter ueberfuehrt werden.

## Eingangszustand
Suche und gespeicherte Filter existieren getrennt, aber der Uebergang fehlt.

## Ausgangszustand
Nutzer koennen aus einer Suche heraus einen benannten, validierten Filter speichern.

## Akzeptanzkriterien
* Die aktuelle Such- oder Filtereingabe wird in den Speichern-Dialog uebernommen.
* Der Nutzer vergibt einen Namen vor dem Speichern.
* Validierungsfehler verhindern das Speichern und zeigen eine klare Meldung.
* Nach erfolgreichem Speichern erscheint der Filter in der Navigation.
